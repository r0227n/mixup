# mixup

楽曲一覧から曲を選択すると、次の2画面で練習タイムラインを編集できます。

1. 音源を再生し、歌詞行と間奏の開始・終了時刻を登録する画面
2. 任意の時間区間を指定し、既存の `mixs/` からMIXを検索・設定する画面

編集結果は曲バンドル内の `practice-timeline.json` へ保存し、元の `lyrics.md` とMIX文書は変更しません。
形式と保存境界は [`docs/practice_timeline/SPEC.md`](../../docs/practice_timeline/SPEC.md) を参照してください。
